# Koko by KoffyKraft

Free, open-source tools for cocoa growers and chocolate makers: farm records, pod harvests,
fermentation and drying with turns, temperatures, moisture and starter yeasts, dry bean lots
with cut test, grade and bean count, bean-to-bar batches, tasting, device-only trails with
photos, and signed lot passports with QR codes.

Live: https://koko.koffykraft.coffee (also https://koko.tagroos.workers.dev)

Built from the KoffyKraft engines (https://github.com/koffykraft/workbook). Read HANDOVER.md first.
